# Alex Carter — AI Automation Specialist & Creative Developer Portfolio

A responsive, ultra-fast, and accessible single-page portfolio site crafted for Alex Carter. Built with a dark luxury aesthetic (#0a0a0b background, #f5f1e8 text, and #c9a96a gold accents), editorial Google typography (Playfair Display headlines and Inter body), and semantic static HTML5, CSS3, and JavaScript.

## Features

- **Dark Luxury Aesthetics**: Deep dark background with high-contrast text, gold accent highlights, subtle SVG grain texture, and glassmorphism blurred sticky navigation.
- **12 Full Sections**:
  1. Sticky Blurred Navigation with AC logo & "Book a Call" CTA
  2. Hero Section with 2026 eyebrow badge, key headline, subheadline, CTAs, and performance stats
  3. Continuous Client Marquee Strip featuring 6 fictional brand partners
  4. Selected Work with 6 distinct projects, results metrics, category tags, and gradient visuals
  5. Specialized Services featuring AI Automations, Web Development, and Brand & Landing Pages
  6. Process Roadmap with 4 clear timeline steps (Discover, Design, Build, Launch & Optimize)
  7. About Section with bio, core competency tags, and portrait visual placeholder
  8. Client Testimonials featuring 5-star ratings and client quotes
  9. Transparent Investment Pricing (Sprint $1,900, Build $4,900, Partner Custom)
  10. Accessible FAQ Accordion with key answers on timeline, ownership, and maintenance
  11. Interactive Contact Form with direct email link (`hello@alexcarter.demo`) and social links
  12. Footer with brand slogan, copyright notice, and scroll-to-top navigation
- **Scroll Reveal & Micro-Interactions**: Smooth entrance animations powered by native IntersectionObserver, hover scale/lift transitions, and interactive form feedback.
- **Accessibility & Performance**: Native HTML5 elements, explicit labels, ARIA landmarks, zero external framework overhead, and sub-second loading performance.

## Tech Stack

- **HTML5**: Semantic tags, ARIA attributes, structured metadata
- **CSS3**: CSS Custom Properties (variables), Flexbox, CSS Grid, animations, and media queries
- **JavaScript**: Native ES6+, IntersectionObserver API, dynamic DOM manipulation
- **Fonts**: Playfair Display & Inter via Google Fonts

## Local Running Steps

### Option 1: Direct File Opening
Simply double-click `index.html` or open it directly in any modern web browser.

### Option 2: Python Local Server (Recommended)
Run a lightweight local HTTP server using Python 3:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your web browser.

### Option 3: Node / NPX HTTP Server
Alternatively, using Node.js:

```bash
npx serve .
```
